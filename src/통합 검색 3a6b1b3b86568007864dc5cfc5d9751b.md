# 통합 검색

Method: GET
Prefix: api/search
상태: 완료
설명: 전체 또는 채팅방 내 검색. 유저, 채팅방, 메시지, 문서를 한번에 검색

### API 내부 로직 흐름

- JWT 토큰 검증
- roomId 유무에 따라 분기
    - roomId 없음 → 전체 검색 (유저 + 내 채팅방 + 메시지 + 문서)
    - roomId 있음 → 해당 채팅방 내 검색 (메시지 + 문서만)
- 각 카테고리별 최근 10개씩 조회
- 200 반환

## Request Header

<aside>

Authorization: Bearer {accessToken}

</aside>

## **Request**

```jsx
GET /api/search?q=소연                    → 전체 검색
GET /api/search?q=소연&roomId=xxx         → 채팅방 내 검색
```
