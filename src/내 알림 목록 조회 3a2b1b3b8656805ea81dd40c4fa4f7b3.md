# 내 알림 목록 조회

Method: GET
Prefix: api/notifications
상태: 완료
설명: 내 알림 목록 조회

### API 내부 로직 흐름

- JWT 토큰 검증→ 실패 시 401 반환
- notifications 컬렉션 조회→ user_id가 본인인 알림만→ 최신순 정렬→ 페이지네이션
- 200 반환

## Request Header

<aside>

Authorization: Bearer {accessToken}

</aside>

## **Request**

```jsx
GET /api/notifications?limit=20&cursor=665f9b8c1d2e3f4051627384
```
