# 채팅방 이름 수정

Method: PATCH
Path: /{roomId}
Prefix: api/rooms
비고: 추가됨
상태: 완료
설명: 그룹 채팅방의 이름을 변경

### API 내부 로직 흐름

- JWT 토큰 검증
→ 실패 시 401 반환
- room_members에서 내가 이 방의 멤버인지 확인
→ 아니면 403 반환
- rooms 컬렉션 조회
→ 존재하지 않으면 404 반환
→ direct 타입이면 400 반환 (1:1은 이름 변경 불가)
- rooms 컬렉션 update
- 200 반환

## Request Header

<aside>

Content-Type: application/json
Authorization: Bearer {accessToken}

</aside>

## **Request**

```jsx
PATCH /api/rooms/{roomId}

{
  "name": "새로운 채팅방 이름"
}
```
