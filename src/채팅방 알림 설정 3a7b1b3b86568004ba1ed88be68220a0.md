# 채팅방 알림 설정

Method: PATCH
Path: /{roomId}/notifications
Prefix: api/rooms
비고: 추가
상태: 완료
설명: 채팅방별 메시지/멘션 알림 수신 여부를 설정

### API 내부 로직 흐름

- JWT 토큰 검증
→ 실패 시 401 반환
- room_members에서 내가 이 방의 멤버인지 확인
→ 아니면 404 반환
- room_members 컬렉션 update
→ notification_settings 업데이트
- 200 반환

## Request Header

<aside>

Content-Type: application/json
Authorization: Bearer {accessToken}

</aside>

## **Request**

```jsx
PATCH /api/rooms/{roomId}/notifications

{
  "message": false,
  "mention": true
}
```
