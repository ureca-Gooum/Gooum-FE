# 알림 전체 읽음 처리

Method: PATCH
Path: /read-all
Prefix: api/notifications
상태: 완료
설명: "전체 읽음" 버튼 클릭 시 모든 알림을 읽음 처리

### API 내부 로직 흐름

- JWT 토큰 검증
→ 실패 시 401 반환
- notifications 컬렉션 update
→ user_id가 본인이고 is_read가 false인 알림 전부 true로 변경
- 200 반환

## Request Header

<aside>

Authorization: Bearer {accessToken}

</aside>

## **Request**

```jsx
PATCH /api/notifications/read-all
```

---

## **Response 200**

```json
{
  "message": "모든 알림을 읽음 처리했어요.",
  "updatedCount": 5
}
```

## Response 401

```json
{ "message": "인증이 필요합니다." }
```
