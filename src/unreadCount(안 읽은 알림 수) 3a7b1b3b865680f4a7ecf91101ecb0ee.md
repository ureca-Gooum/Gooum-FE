# unreadCount(안 읽은 알림 수)

callback: No
방향: 서버 → 클라이언트
상태: 시작 전
설명: 연결 즉시 자동 전송. 프론트에서 알림 뱃지 숫자 표시용

### unreadCount

[Socket.io](http://socket.io/) 연결 시 자동으로 안 읽은 알림 수 + 채팅방 수 전달

**방향:** 서버 → 클라이언트

**설명:** 연결 즉시 자동 전송. 프론트에서 알림 뱃지 숫자 표시용

---

**데이터:**

```json
{ 
  "notifications": 5, // 안 읽은 알림 수 (알림 아이콘 뱃지)
  "rooms": 3 // 	안 읽은 메시지가 있는 채팅방 수 (채팅 아이콘 뱃지)
}
```
