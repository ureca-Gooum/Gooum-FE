# 알림 읽음 처리

Method: PATCH
Path: /{notificationId}
Prefix: api/notifications
상태: 완료
설명: 알림 클릭 시 해당 알림을 읽음 처리

### API 내부 로직 흐름

- JWT 토큰 검증
→ 실패 시 401 반환
- notifications 컬렉션 조회
→ 해당 알림이 본인 것인지 확인
→ 아니면 404 반환
- notifications 컬렉션 update
→ is_read를 true로 변경
- 200 반환

## Request Header

<aside>

Authorization: Bearer {accessToken}

</aside>

## **Request**

```jsx
PATCH /api/notifications/{notificationId}
```

[Path Parameters](Path%20Parameters%20a09b1b3b8656827480dc0103633297cb.csv)

## **Response 200**

```json
{
  "notificationId": "665f9b8c1d2e3f4051627384",
  "isRead": true
}
```

## Response 401

```json
{ "message": "인증이 필요합니다." }
```

## Response 404

```json
{ "message": "알림을 찾을 수 없어요." }
```
